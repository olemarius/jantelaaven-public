# jantelaaven-public

Offentlig hosting av **én** statisk fil: `finn-origin.ics`.

Dette er en iCal-feed med Finn-only opptatt-netter for hytta på Mosetra (Trysil),
brukt til å blokkere de nettene på Airbnb, Booking.com og jantelaaven. Fila
inneholder **ingen persondata** — kun dato-range og en opak UID.

Fila speiles automatisk hit fra et privat kildrepo. **Ikke rediger den her** —
endringer blir overskrevet ved neste speiling.

Feed-URL:

```
https://olemarius.github.io/jantelaaven-public/finn-origin.ics
```
